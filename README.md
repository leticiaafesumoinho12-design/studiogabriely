# Studio Gabriely

Um projeto integrador que apresenta um site criado com HTML, CSS e JavaScript.

## 📖 Sobre o Projeto

Este repositório contém o código-fonte de um site desenvolvido para o “Studio Gabriely”. A ideia do projeto é oferecer uma página web funcional, responsiva e bem estruturada, usando apenas tecnologias web básicas (HTML, CSS e JavaScript).

## 🧰 Tecnologias Utilizadas

- HTML  
- CSS  
- JavaScript
